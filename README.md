# Internationale-ZH-345

《国际歌》（L’Internationale）法文原第 3、4、5 段的中文**可唱译配试作**。

目标不是逐字直译，而是在尽量保留鲍狄埃原意的前提下，让缺失的三段能够自然接入现行中文演唱版本的旋律、重音和语言习惯。

> 当前状态：**v0.1.0 / 首次公开草案**  
> 已经过多轮按旋律默唱修改，尚待正式伴奏与更多实际演唱反馈。

## 为什么是 3、4、5 段？

鲍狄埃的法文原词共有六段。中文早期译配与后来广泛传唱的三段版本，沿用了原第 **1、2、6** 段的取舍；上海音乐出版社的资料也记载，瞿秋白当年的译配选择了原词第 1、2、6 段。

因此本项目只处理长期没有进入中文通行唱本的原第 **3、4、5** 段。

- 第 3 段：国家、法律、税收、权利与义务
- 第 4 段：劳动、财富与资本所有者
- 第 5 段：战争、军队与劳动者之间的冲突

## 当前译配

### 原第三段

国家压迫，法律尽欺骗，  
苛捐重税榨穷苦人；  
富人从来不负半点责，  
穷人权利成空文。  
受够了这管束和锁链，  
平等要立新章程；  
无权利就不应负义务，  
无义务就不应享有权！

### 原第四段

矿山铁路那些大财阀，  
耀武扬威何等可憎；  
除了掠夺我们的劳动，  
可曾立下半点功！  
劳动创造所有的财富，  
尽归他们的囊中；  
人民所求不过是公道，  
拿回我们应得那一份！

### 原第五段

帝王用战争迷惑我们，  
劳动者联合求和平；  
停止操练，离开这队伍，  
枪口向下散军营！  
若是暴君逼我们卖命，  
要我们去当英雄；  
暴君终将听见这回答：  
子弹射向我们的将军！

## 译配原则

1. **先能唱，再谈逐字对应。** 音节数量、换气与旋律重音优先于机械直译。
2. **句尾必须能“落住”。** 例如把段尾从“权利”的“利”改为直接落在“权”上。
3. **歌词必须第一耳朵就听懂。** 避免需要回读才能分清施受关系的句子。
4. **不主动削弱原词。** 原文中具体而尖锐的表达，尽量保留其方向和力度。
5. **重复可以是修辞。** 如果重复在旋律中形成推进，不为“避免重复”而机械删改。

## 欢迎反馈

最有价值的反馈不是“读起来顺不顺”，而是**实际唱起来哪里有问题**。

如果你愿意跟伴奏试唱，请优先指出：

- 哪一句音节塞不进去；
- 哪个中文重音和旋律重音打架；
- 哪个句尾拖音不自然；
- 哪一句存在歧义；
- 哪一处为了唱感牺牲原意过多。

可以直接开 Issue，也欢迎提交 Pull Request。
